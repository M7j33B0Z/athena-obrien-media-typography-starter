# Media and Typography Starter

Use this small page for Module 4 practice if you do not want to use your capstone yet.

## Files

- `index.html`: sample content with media and typography tasks.
- `styles.css`: starter CSS with tokens and prompts.
- `assets/sample-icon.svg`: simple SVG for accessibility treatment practice.

## Practice goal

Build a media and typography optimization pass:

- responsive image markup
- dimensions or aspect-ratio protection
- SVG treatment
- typography tokens
- fluid type or spacing
- font fallback strategy
- zoom and slow-network notes

The starter uses placeholder image paths so you can replace them with your own exported image variants.

+ My placeholder image is a JPG file. I included three different widths: 250px, 800px, and 1200px. This is my own, original image. The purpose of creating this responsive image in multiple sizes is so that it can be viewed on multiple different devices and still be visible to all viewers. If the image was too large or too small on a certain device, then it would make the rest of the website difficult to read.


## Decisions
One media decision I made was to fix the proportions of my image to be 5/6. I chose to do this because, when I set specific dimensions for my image, it resized awkwardly. You could see a lot of the background of the image, but little of the actual picture of me, which is the main focus. One typography decision I made was to include two different font weights for the headings. I wanted heading one to be distinct from heading two, but still be the same typeface. To prevent my layout from shifting, I placed my additional SVG inside of its own div. When I tried to place it inside the other divs, it disrupted the flow of the flexbox content.
